# static/assets — replaceable files

Full rules (formats, sizes, naming, manifest format): `docs/10-assets-guide.md`.

- Replace a file: drop in a new file with the SAME name.
- Add a file: drop it in AND add an entry to the folder's manifest.json.
- New avatar pack: copy avatars/default → rename → edit manifest → set AVATAR_PACK in .env.
